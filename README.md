# Desktop Pilot

A Windows assistant using cloud Gemini, local tools, and Obsidian memory. Removal operations require explicit, operation-specific user approval.

**Status:** initial local foundation implemented; this is not yet a system-control application. The native preview supports read-only vault search and records paused task states. See [implementation status](docs/implementation-status.md) and [setup](docs/setup.md).
